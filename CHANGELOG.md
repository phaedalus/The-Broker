# Changelog

## 1.0.0

- Added private, voice-channel-based matchmaking intake.
- Added PAYDAY, platform, activity, style, region, and experience matching.
- Added instant crew creation and compatible automatic matching.
- Added owner controls for matching, visibility, waiting time, renaming, and kicking.
- Added same-game queue visibility without exposing rooms server-wide.
- Added restart recovery, stale intake cleanup, and solo-room expiry.
- Added `/broker_setup`, `/queue_status`, `/ping`, and `/about`.
- Added rotating activity statuses and conservative six-hour avatar rotation.
